04 · building the call

One prompt template.
Any number of metrics.

src/packing/criteria.py    def render(self) -> str:
        """Rubric block for the judge prompt."""
        lines = [f"### {self.label} ({self.key})", self.description, "", "Scale:"]
        for value in sorted(self.anchors):
            lines.append(f"  {value} = {self.anchors[value]}")
        return "\n".join(lines)

Every metric renders the same way: name, definition, and a description for each score.

src/packing/prompt.py## Rubric ({len(group)} {plural})

{_rubric_block(group)}

## Task

Score the response on each of the {len(group)} {plural} above, independently. \
For each one, give a short verbatim quote as evidence, one or two sentences of \
reasoning, and then the integer score.

The rubric block grows. The instructions never change.

16 · takeaway

If you run judges in production

  • Pack a small rubric. Five is a safe start.
  • Retest as it grows, per metric type.
  • Describe every score on the scale.
  • Report ties next to accuracy.
